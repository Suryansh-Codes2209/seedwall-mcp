Remote MCP server · Claude Code plugin

Generative art for anywhere on your site.

Seedwall MCP lets Claude, or any MCP client, render every Seedwall generative look at any size: hero and section backgrounds, OG images, README banners, blog covers and wallpapers. You get SVG and PNG links, and the model gets a preview so it can check its own work.

Tools

Four tools. All of them are read-only and idempotent: they never change anything, and the same input always returns the same image.

list_looksread-only

Lists every look (generator) with its presets, plus the colour themes and device sizes. Claude usually calls it first. It takes no arguments.

describe_lookread-only

Shows one look's params: colours and their roles (bg, fg, accent), shape and density controls with their ranges, the shared text layer, and the presets.

ArgumentTypeDescription
lookstring, requiredLook id from list_looks, e.g. topographic.

renderread-only

Renders a look at any size. It returns a stable SVG URL, a PNG URL, a studio link for fine-tuning it by hand on seedwall.suryansh.work, the fully resolved params, and a small PNG preview the model can look at.

ArgumentTypeDescription
lookstring, requiredLook id.
presetstringPreset id. Defaults to the look's first preset.
themestringRecolours the look with an editor theme: dracula, nord, tokyo-night, gruvbox, catppuccin, one-dark, rose-pine, solarized, github-light.
paramsobjectParam overrides from describe_look, e.g. {"bg":"#0b1020","levels":30}. Colours are #rrggbb. Invalid values are ignored, not errors.
width, heightinteger, 16–6144Size in pixels. Default 1920×1080.
devicestringA device id instead of a size: macbook14, 1080p, 1440p, 4k, ultrawide, iphone, android, ipad, …
text_freebooleanHides the look's built-in quote. Use true for anything behind your own content.
seedinteger, 0–999999Varies the random layout while keeping the look. Same seed, same image.
previewbooleanInclude a ≤640 px PNG preview. Default true.

Rendered topographic / survey at 1600×900.

PNG: https://seedwall.suryansh.work/api/render?g=topographic&p=survey&w=1600&h=900&x=…

[image: 640×360 preview]

seedread-only

Every number from 1 to 999999 is one fixed Seedwall image, the same for everyone. Leave out seed to get today's daily wallpaper. It's good for “surprise me”.

ArgumentTypeDescription
seedinteger, 1–999999Leave out for today's seed (UTC).
width, heightintegerDefault 1920×1080.
previewbooleanDefault true.

Sizes & use cases

Generators lay out relative to the shorter side, so any aspect ratio works. These are good starting sizes.

UseSizeTips
Full-width hero1920×1080text_free, low contrast where the headline sits, CSS background-size: cover. Add a portrait 1080×1920 version for phones if the composition matters.
Wide banner / section2400×1000Calm looks such as wave-lines, mesh-gradient and aurora sit well behind content.

GitHub social preview1280×640Upload it under the repo's Settings → Social preview.
README banner1500×500Download it into the repo and use a relative path.
WallpaperdeviceUse a device id, with text on if you want a quote.

Wiring a background (CSS)

.hero {
  /* Seedwall: <studio link> — open to regenerate or tweak */
  background: #0b1020 url("/seedwall/hero.svg") center / cover no-repeat;
}
css

Download the SVG into your repo rather than hotlinking it. If a dense look's SVG is over ~300 KB, use the PNG URL (or WebP) instead.

The Claude Code plugin

The plugin bundles this server with a seedwall skill, which teaches Claude to treat generative art as a project asset rather than a one-off image.

  1. Reads your project: the framework, the component that owns the section, where static assets live, and your brand colours from the Tailwind config, CSS variables or design tokens (including dark-mode values).
  2. Picks and renders a look without text, in your colours, at the right size. It checks the preview and iterates two or three times when the art is busy behind the headline.
  3. Downloads the file into public/seedwall/ (or your framework's equivalent) instead of hotlinking it, and falls back to PNG/WebP for heavy SVGs.
  4. Wires it in: CSS cover or next/image with fill, decorative markup (alt=""), a scrim for contrast, a dark-mode version with the same seed, and an optional portrait version for phones.
  5. Checks WCAG contrast for the headline over the art, and leaves a comment with the studio link so anyone can regenerate the art later.

Source: plugin/ on GitHub.

How it works

The server is a thin, stateless layer. Seedwall's generators are pure TypeScript functions: (look, preset, params, size, seed) → SVG. The same inputs always produce byte-identical output.

→
Seedwall MCPstateless, no storage
→
Seedwall API/api/generators · /api/render
→
SVG / PNGcached at the edge, stable URLs
Endpointhttps://mcp.seedwall.suryansh.work/mcp
TransportStreamable HTTP. Every request is independent: no sessions and no GET/SSE stream.
ProtocolMCP 2026-07-28, with stateless fallback for 2025-era clients.
AuthNone. All the data is public.
LimitsAt most 6144 px per side. Bigger requests are scaled down to fit, keeping the aspect ratio.
ErrorsUnknown looks, presets or themes come back as tool errors (isError: true) with a message listing the valid options.

HTTP API

You don't need MCP to use any of this. The tools are built on two public endpoints that you can call from scripts, build steps or CI.

GET /api/render

It takes the same query as a Seedwall studio link, so any studio URL can become an image URL.

QueryDescription
gLook id (required).
pPreset id.
w, h or dSize in pixels, or a device id.
xParam overrides: base64url-encoded JSON (no padding), e.g. {"text.none":true} → eyJ0ZXh0Lm5vbmUiOnRydWV9.
tTheme id.
formatpng (default), svg, or json for { svg, png, studio, params, size }.
 
curl -o hero.svg "https://seedwall.suryansh.work/api/render?g=aurora&w=1920&h=1080&format=svg"
curl "https://seedwall.suryansh.work/api/render?g=topographic&t=nord&w=1200&h=630&format=json"
sh

GET /api/generators

The full catalogue: every look with its param schema and presets, plus themes and devices.

curl "https://seedwall.suryansh.work/api/generators"
sh

FAQ & troubleshooting

Opening this URL in a browser shows this page, not the MCP server. Is it working?
Yes. The MCP endpoint is /mcp, and it only answers MCP POST requests. Paste https://mcp.seedwall.suryansh.work/mcp into your client, not this page's URL.
claude.ai says it can't connect
Check that the URL ends in /mcp and that the OAuth fields are empty, since the server needs no auth. Custom connectors may need to be enabled by your workspace admin on Team and Enterprise plans.
The tools appear but every call fails
The server forwards renders to seedwall.suryansh.work. If that site is down, the tool error says so. Try again in a minute, or open an issue.
Can I use the images commercially?
Yes. The art is generated for you from your parameters. The code is MIT licensed. Credit is appreciated but not required.
Will the image at a URL ever change?
Output is deterministic for a given Seedwall release, but a generator fix could change pixels. That's why the plugin downloads files into your repo. Hotlink only when you want a live, daily-changing image (such as /api/daily).
Can I self-host it?
Yes. Clone the repo, run npm install && npm run dev, and point SEEDWALL_URL at your own Seedwall instance if you have one. It deploys to Vercel as is.

Privacy

The server has no accounts and no database, and stores nothing. Tool arguments (look, colours, size and so on) are forwarded to seedwall.suryansh.work to render the image. Standard hosting request logs apply. No personal data is collected, and nothing is used for training or analytics.
